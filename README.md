# 中学时期的 BASIC 程序（1991–1994）

软件项目，1991-04 起。源码不贴，备份位置：wenshu 备份 `<用户名>-pre2011/0A-Me-PreISU/6-编程/0-Basic/Basic`。

**是什么**：高中到大学初期用 GW-BASIC / QBasic 写的小程序，按用途分在 GAME（游戏，如 DONKEY、HUOJIAN 火箭、QICHE 汽车、MONEY）、DRAW（画图与动画，DONGHUA1–3、FEIJI 飞机）、MUSIC（音乐，YINYUE）、EXERCISE（练习 BASIC-1…48、QB 练习）、COMMON（常用小工具，如 WNL 万年历、JIAFA 加法练习）等目录，另有 PRIVATE.BJ/XINNIAN（新年贺卡）。

**语言**：BASIC（GW-BASIC / QBasic）

**规模**：357 个文件，其中 .BAS 源文件 333 个，约 8,900 行。部分文件时间戳为 1979-12（DOS 未设时钟的默认值），有效时间约 1991-04 至 1994-08。
